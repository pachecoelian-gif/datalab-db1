Consulta / respuesta:

WHERE fuente = 'externa'

EJERCICIO 16
Consulta / respuesta:
SELECT nombre_metrica, AVG(valor) AS promedio
FROM dbo.metrica
GROUP BY nombre_metrica
HAVING AVG(valor) > 0.80;
Observaciones:
AVG no puede ir en WHERE porque este filtra fila por fila antes de agrupar, cuando el promedio todavía no existe (SQL Server da el error 147). HAVING filtra los grupos ya calculados. Con la semilla devuelve 0 filas porque ningún promedio supera 0.80; es un resultado válido, no un error.

----------------------------------------

EJERCICIO 17

EJERCICIO 18
Consulta / respuesta:
-- Antes
SELECT id_proyecto, nombre_proyecto, descripcion
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto de práctica S08';

UPDATE dbo.proyecto
SET descripcion = N'Descripcion actualizada durante la practica S08.'
WHERE nombre_proyecto = N'Proyecto de práctica S08';

-- Después
SELECT id_proyecto, nombre_proyecto, descripcion
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto de práctica S08';
Observaciones:
El SELECT previo confirma que el WHERE apunta a una sola fila, el UPDATE reporta 1 fila afectada y el SELECT final muestra la nueva descripción. Sin WHERE se habrían modificado todos los proyectos.

----------------------------------------
