# DataLab — Base de Datos

Proyecto desarrollado para el espacio académico **Bases de Datos** del programa de **Ingeniería de Datos e Inteligencia Artificial (IDIA)**.

El proyecto consiste en diseñar y desarrollar progresivamente una base de datos para **DataLab**, una plataforma interna utilizada por un equipo de ciencia de datos para gestionar proyectos de inteligencia artificial, datasets, experimentos, modelos y métricas.

## 🎯 Descripción del proyecto

DataLab permite llevar el control de:

- Científicos de datos.
- Proyectos de inteligencia artificial.
- Datasets utilizados.
- Experimentos realizados.
- Modelos entrenados.
- Métricas obtenidas.

El diseño de la base de datos se desarrollará progresivamente durante el semestre, pasando del **modelo conceptual** al **modelo relacional**, SQL y posteriormente a una extensión documental con MongoDB.
